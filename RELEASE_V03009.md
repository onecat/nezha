# Dashboard v0.30.09

Linux amd64 only. Replaces the obsolete legacy Agent CLI clipboard entry with a one-command install/reinstall generated from the authenticated HTTPS Dashboard page. The embedded script is SHA256-pinned in the copied command; Agent secrets are passed through stdin to the local installer, never to the script download endpoint. Initial installation downloads the independently published v0.30.02 Agent and Supervisor with exact pinned release checksums. It requires root, systemd, curl, python3 and standard Linux administration tools.

Retains official v0 layout /opt/nezha/agent and nezha-agent.service. The legacy executable path is a compatibility symlink to the managed worker. Root-owned service and Supervisor, a dedicated non-root nezha-agent service account, private managed configuration, signing key pinning and durable ledger. Initial migration backs up the prior directory and service; it refuses an existing separate managed Supervisor or custom drop-ins. Existing installations made by this installer are repaired at the ledger's installed release version, never resetting the sequence or changing server identity; unresolved tasks require reconciliation. Existing monitoring config is preserved on reinstall. No upstream installer or upstream update endpoint. Old legacy Agent features not present in the independent Agent remain unavailable.

Requires automatic URL upgrade mode (explicit HTTP and gRPC loopback, TLS true, no manual provisioning override), same-host TLS proxy and authenticated local superadmin. Private CA may be supplied via NZ_AGENT_CA_FILE on initial installation. The copied command contains the server credential; protect terminal history. The release job is gated on native systemd migration/reinstall, real URL upgrade, existing rollback and security regressions. Dashboard assets remain nezha-app and SHA256SUMS.
