CI 45841895363 passed Go verification, Go scan, frontend audit, actual terminal and multi-chunk file upload/download checksum; NAT failed with HTTP parser detecting bytes after Connection: close. Legacy V0 Agent handleNATTask emits an independent error-text frame on TCP read EOF, then CloseSend. Unit tests cover these cases, including non-EOF transport failures, and NAT integration includes chunked, fixed-length and literal EOF response bodies. A standalone EOF payload on an open NAT stream may wait for the next frame (legacy protocol has no typed end marker); other Agent versions and non-graceful error-text frames are not fully covered. This fix is based on the identified legacy behavior; successful HTTP regression is still required. Existing NAT request buffering and concurrent task sending remain review topics.
