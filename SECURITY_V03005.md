SSRF policy: notification and DDNS webhooks now use dedicated HTTP(S) transports with per-dial IP validation, no environment proxy, same-origin redirects only, bounded timeouts and response bodies. Default rejects private, loopback, link-local and special-use addresses. Explicit private destinations may be enabled in config.yaml with webhookallowedcidrs (e.g. ["10.20.0.15/32"]); restart required. Link-local and known metadata addresses remain blocked. VerifySSL defaults to true if unspecified; explicit false remains supported. Existing internal webhooks or proxy-only endpoints may require configuration changes. User-configured Agent monitor destinations are not affected.
