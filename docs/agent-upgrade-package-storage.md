# Verified release storage

A Linux-only Dashboard storage component stages a bounded upload in a private operator-owned directory, verifies the signed manifest and package contents, syncs the file, and publishes it by digest without replacing an existing object. Reopening verifies the same file descriptor before handing it to a future transfer caller. No network handler, executable extraction or install is provided. Caller must enforce operator authorization, upload deadlines, total disk quotas, release catalog and retention. A context cannot interrupt an arbitrary blocked source Read: the future upload handler must impose transport deadlines. The directory and its ancestors must be trusted; no shared writable directory or network filesystem. A directory sync failure can leave an already published object, which is safe to retry and verify. The module is not connected to Dashboard startup. Tests run in the existing Linux storage CI job and exercise verification, duplicate import, corruption and cleanup.
